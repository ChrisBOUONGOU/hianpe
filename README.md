## 🛠️ Project technology / Technologies du projet

This repository contains the Hianpe website, built with **Symfony 8.1 and PHP 8.4**. The homepage and product pages are rendered by Symfony controllers.

Ce dépôt contient le site web Hianpe, développé avec **Symfony 8.1 et PHP 8.4**. La page d’accueil et les pages des logiciels sont générées par des contrôleurs Symfony.

### Run locally / Lancer le projet en local

**Prerequisites / Prérequis:** PHP 8.4+, Composer, and Symfony CLI (recommended / recommandé).

```bash
composer install
symfony serve
```

Then open the local address displayed by Symfony CLI.  
Ouvrez ensuite l’adresse locale affichée par Symfony CLI.
